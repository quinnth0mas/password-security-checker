      Step 3: Check known data breaches

      See whether this exact password has leaked before, in every source you have set up.

      Your browser makes a one-way fingerprint (SHA-1) of the password and sends only the first 5 characters of it. The service replies with every match for that start, and your browser looks for yours locally, so the service cannot tell which password you tested.

      Advanced: add more breach sources

      Built in: the online Pwned Passwords service. You can add two kinds of extra source. Both are optional and checked together when you press the button.

      One address per line, up to 3. Each must answer in the Pwned Passwords range format: the address, a slash, then the first 5 characters of the SHA-1 hash. Self-hosted mirrors work. Every address you add receives the same 5-character prefix, so add only servers you trust. Works in the standalone copy; the published page cannot reach other sites.

      Offline lists

      Up to 5 files at once, holding at most 1,000,000 hashes and 1,000,000 passwords in total. Plain passwords, one per line, are checked for an exact match and also feed the common-password check. SHA-1 hashes, one per line, as HASH or HASH:COUNT (the Have I Been Pwned download format), are checked against the password's hash. Files are read in your browser and never uploaded. Only the first 25 MB of each file is read, so load trimmed lists.

      Step 4: Protect the account

      A strong password is one lock. These habits add more.

      • One account, one passwordReused passwords let one breach open every account.
      • Use a password managerIt makes and fills in a random password for each account.
      • Turn on 2FAA second step protects the account even if the password leaks.

      Turn on two-factor sign-in

      • Best: a passkey or a hardware security key.
      • Good: an authenticator app that makes a 6-digit code. Text-message codes are better than nothing but can be intercepted.
      • Save the backup codes somewhere offline, so losing your phone does not lock you out.
      How the checks work and what they can miss
      16 characters minimum
      Each added character multiplies the number of guesses an attacker needs. Sixteen is a practical floor for anything that matters.
      Letters, numbers and symbols, nothing else
      The password must use all three kinds and stay within standard keyboard characters, with no spaces, accents or emoji. Some sites reject those characters. For a phrase, join words with - or _.
      Common and breached passwords fall first
      Attackers try leaked-password lists and their variations before anything else. Swapping a for @ or adding 123! at the end is built into their tools.
      Patterns are shortcuts
      Keyboard runs, sequences, repeats and years cut the search space sharply.

      The bit count is a rough estimate from length, character types and detected patterns. The built-in list is a curated set of common passwords, names and words, each matched with case changes, look-alike characters and added digits or symbols. It is much smaller than the multi-million-entry lists attackers use, which is why the breach check and "Add your own lists" exist. A password that is not found in a breach is not proven safe, only not yet known to be exposed. Use this page as a screen for obvious problems, not a guarantee.
