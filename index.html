    Check known data breaches

    Source 1, online: the Pwned Passwords collection from Have I Been Pwned. Your browser hashes the password (SHA-1) and sends only the first 5 characters of that hash. The service returns every matching hash ending, and your browser looks for yours locally, so the service cannot tell which password you tested.

    Source 2, offline: a breached-password hash list you load below. It is checked on this device and nothing is sent.

    What to improve

      Add a second lock: turn on two-factor sign-in

      • Best: a passkey or a hardware security key.
      • Good: an authenticator app that makes a 6-digit code. Text-message codes are better than nothing but can be intercepted.
      • Save the backup codes somewhere offline, so losing your phone does not lock you out.

      Your own lists

      Accepts plain passwords, one per line, which are added to the common-password check. It also accepts SHA-1 hashes, one per line, either as HASH or HASH:COUNT (the Have I Been Pwned download format), which become the offline breach source. Files are read in your browser and never uploaded. Only the first 25 MB of a file is read, so load a trimmed list.

      Why these rules

      16 characters minimum
      Each added character multiplies the number of guesses an attacker needs. Sixteen is a practical floor for anything that matters.
      Letters, numbers and symbols, nothing else
      The password must use all three kinds and stay within standard keyboard characters, with no spaces, accents or emoji. Some sites reject those characters. For a phrase, join words with - or _.
      Common and breached passwords fall first
      Attackers try leaked-password lists and their variations before anything else. Swapping a for @ or adding 123! at the end is built into their tools.
      Patterns are shortcuts
      Keyboard runs, sequences, repeats and years cut the search space sharply.

      The bit count is a rough estimate from length, character types and detected patterns. The built-in list is a curated set of common passwords, names and words, each matched with case changes, look-alike characters and added digits or symbols. It is much smaller than the multi-million-entry lists attackers use, which is why the breach check and "Add my own list" exist. A password that is not found in a breach is not proven safe, only not yet known to be exposed. Use this page as a screen for obvious problems, not a guarantee.
